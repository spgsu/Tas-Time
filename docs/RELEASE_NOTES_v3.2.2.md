# Tas-Time 3.2.2

Tas-Time now tells you when your book file is behind.

## What changed

- **Warning when the file is behind.** If your linked book file is missing recent edits, for example because the browser is waiting for you to **Reconnect**, closing Tas-Time shows the browser's "Leave site?" prompt. Stay, click Reconnect, and the file catches up. When the file is up to date, Tas-Time closes without asking.
- Your edits are still kept in the browser's recovery copy, so choosing to leave loses nothing. They come back on the next launch, ready to reconnect.

## Upgrading

No change to the book format (still format 4). Replace the application files.

## Downloads

- **Windows:** extract Tas-Time-Windows.zip and run Open Tas-Time.cmd.
- **macOS:** extract Tas-Time-macOS.zip; first launch, right-click Open Tas-Time.command and choose Open.
- **Single HTML:** open Tas-Time.html in Edge or Chrome.
