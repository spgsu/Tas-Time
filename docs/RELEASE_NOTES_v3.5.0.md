# Tas-Time 3.5.0

Action menus: every job and task action has a second way in.

## What changed

- **⋯ menus on jobs and tasks.** Jobs in the sidebar and in Plan, and tasks in Plan, Board, Week, Today, Lookahead and Assignments, now have a **⋯** menu. Jobs: Edit, Rename, Show only this job, Add task, Open notebook, Active / On hold / Complete, Archive, Delete. Tasks: Edit, Rename, Mark done or Reopen, Mark doing, Work on it today, Duplicate, Archive, Delete. The menus work by keyboard (arrow keys, Enter, Esc) and with screen readers, and do exactly what the editor panel does, including the confirmation before completing a job with unfinished tasks.
- **Name fields are visibly editable.** In the editor panel, the job or task name now has a label and a border. It previously looked like a heading.
- **The job panel follows your selection.** With Edit job open, picking another job in the sidebar now switches the panel to that job instead of continuing to show the previous one.

## Upgrading

No change to the book format. Replace the application files.

## Downloads

- **Windows:** extract Tas-Time-Windows.zip and run Open Tas-Time.cmd.
- **macOS:** extract Tas-Time-macOS.zip; first launch, right-click Open Tas-Time.command and choose Open.
- **Single HTML:** open Tas-Time.html in Edge or Chrome.
